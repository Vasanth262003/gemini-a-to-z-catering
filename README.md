# Gingeraz Catering Website

Static single-page catering website.

## Files
- `index.html` — complete website (HTML + CSS, no build step)
- `CNAME` — custom domain configuration from the original project context

## Run locally
Open `index.html` in a browser.

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and `CNAME`.
3. Enable GitHub Pages from the repository settings.
4. Point the DNS for your domain to the hosting provider.

## Before publishing
Replace the placeholder email, phone number, service area, and any sample menu copy with the real business details.
